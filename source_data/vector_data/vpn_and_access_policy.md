# VPN and Access Policy

Owner: Security team. Last reviewed: 2026-06-01.

## Who gets VPN access

VPN access is granted to employees who have completed the security training and have a company-managed laptop. Contractors need written approval from the Security Lead before VPN access is enabled.

## Authentication

All access goes through Okta. Multi-factor authentication is mandatory for every account. Hardware security keys are required for production access and for anyone with admin rights.

## Access reviews

Managers review their team's access every quarter. The Security team removes access within 24 hours of an employee leaving. Access to production data requires a ticket approved by the data owner.

## Reporting a lost device

Report a lost or stolen laptop or key to the Security team immediately, and no later than one hour after you notice. Security will revoke sessions and wipe the device remotely.
